# ITMSD 1 Laboratory Exercise 03
## React Native Fundamentals

This project contains the completed activities for Laboratory Exercise 03
using Expo SDK 57, React 19, and TypeScript.

## Requirements

- Node.js
- npm
- Expo
- Expo Go

## Installation

Clone the repository:

git clone https://github.com/mharcelmj/ITMSD1_Lab3_Lolo_LeandroAlexis.git

Go to the project folder:

cd ITMSD1-Lab03-React-Native

Install dependencies:

npm install

## Run the Project

Start the Expo development server:

npx expo start

Then scan the QR code using Expo Go or run the project
using an available emulator.

## Laboratory Modules

1. Expo & CLI Helper
2. Core Primitives
3. Modular Props
4. Dynamic State
5. Flexbox Visualizer
6. Synthesis App
